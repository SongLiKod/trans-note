# 《途记交通备忘录》产品需求文档
软件英文名：TransNote
安卓包名：com.transnote.traffic
应用类型：纯本地离线安卓工具APP，**无后台服务器，不上传用户任何数据**
最低兼容：Android 10（API29）；目标SDK：Android14（API34）

## 1. 产品概述
### 1.1 产品简介
途记交通备忘录是一款本地化公交、地铁线路个人记录工具。用户可手动录入或拍照识别公交站牌，自定义公交线路（区分上行/下行）、地铁线路；可以为每一个公交站点、地铁每个出入口添加文字、图片、地图备注；支持地点反向查询所有可达公交地铁线路，支持站点标记地铁接驳换乘点。所有数据保存在手机本地，无需联网、无后端、无账号登录。

### 1.2 竞品分析
市面主流APP（车来了、掌上公交、Moovit）优点：官方线路齐全、支持实时车辆到站、路线规划。
缺点：
1. 不支持用户自定义录入线路，无法记录临时改线、冷门支线；
2. 无法给站点、地铁出口增加个人备注、实景图片；
3. 地铁出口信息简陋，无法单独记录每个出口对应的道路、地标；
4. 检索只能查线路规划，不能根据地名反向查找所有途经线路；
5. 无法自定义标记公交站点和地铁口的接驳关系。

本产品差异化优势：
- 完全自定义录入公交/地铁线路，拍照OCR识别站牌；
- 精细化备注：公交站点、地铁每个出入口独立备注文字、图片、地图点位；
- 公交线路支持上行、下行两套独立站点，一键切换预览；
- 离线双向检索：搜线路查站点 / 搜地点查全部可达线路；
- 可视化地铁接驳标记；
- 纯本地存储，无数据上传；
- 主题支持跟随系统 / 浅色 / 深色模式，全套配色。

## 2. 用户核心需求
1. 录入：拍照识别站牌 或 手动录入公交/地铁线路；
2. 编辑：线路、站点可增删改，公交线路区分上行下行，可拖拽调整站点顺序；
3. 站点备注：公交站点增加文字备注、图片、地图点位，标记是否为地铁接驳站；
4. 地铁精细化管理：地铁站点可新增多个出入口，每个出口独立备注道路、地标、图片、位置；
5. 线路预览：线路详情一键切换上行/下行，地图展示站点轨迹；
6. 检索：正向检索（输入线路查看站点），反向检索（输入地名，查询所有能到达此地的公交地铁）；
7. 主题：APP主题三选一：跟随系统、浅色模式、深色模式，切换实时生效；
8. 数据管理：本地保存全部数据，支持本地导出备份包、导入恢复备份。

## 3. 功能详细需求
### 3.1 线路录入模块
1. 拍照录入：调用相机拍照或相册选择站牌图片，本地离线OCR识别文字，自动填充线路、站点、运营时间，识别结果支持人工修改；
2. 手动录入：选择线路类型（公交/地铁），填写线路名称、首末班、票价；逐站添加站点，拖拽排序站点；
3. 公交线路独立存储上行、下行两套站点列表，双向站点可以不一样。

### 3.2 公交线路与站点管理
1. 线路详情：一键切换上行/下行，列表展示站点，地图绘制站点轨迹；
2. 站点编辑：站点名称修改、删除；添加文字备注、上传实景图片、标记地图经纬度；
3. 接驳标记：站点可绑定地铁出入口，高亮显示【地铁换乘】标签，点击跳转对应地铁出口详情。

### 3.3 地铁线路与出入口管理
1. 录入地铁线路、地铁站点；
2. 一个地铁站点可以新增多个出入口（A口、1号口等）；
3. 每个出入口独立编辑：出口名称、对应道路、地标信息、通行备注、图片、地图定位。

### 3.4 搜索检索模块（离线本地检索）
1. 正向搜索：输入线路编号/名称，匹配线路，进入线路详情；
2. 反向搜索：输入地名/道路/地标，在本地数据库检索站点名、站点备注、地铁出口备注，展示所有匹配线路与站点；
3. 搜索结果点击直接跳转线路或站点详情。

### 3.5 数据备份模块
1. 导出：数据库+图片打包为ZIP备份文件，保存到手机本地；
2. 导入：读取本地ZIP备份包，恢复全部线路、站点、图片数据。

## 4. UI设计规范
- UI框架：Material3
- 圆角：卡片12dp，按钮8dp，弹窗16dp
- 间距：全局外间距16dp，组件间距8dp/12dp
- 字体：系统无衬线字体；一级标题18sp，正文16sp，提示文字13sp，跟随系统字体缩放
- 动画：页面左右切换、列表渐入、水波纹点击；主题切换全局淡入淡出

## 5. 非功能需求
1. 离线优先：录入、编辑、搜索、备注全部离线；仅地图瓦片加载需要网络；
2. 性能：本地检索秒响应，大量站点列表滚动流畅；
3. 数据安全：所有数据存储在APP私有目录，不上传服务器；APP卸载数据会清空，依赖本地备份；
4. 无广告、无推送、无埋点统计；
5. 适配全面屏、挖孔屏，沉浸式状态栏。

## 6. 开发里程碑
一期（最小可用版）
- 主题系统、深浅色+跟随系统
- Room数据库，手动录入公交地铁线路，上行下行管理
- 站点文字备注、地图打点
- 本地双向搜索

二期（功能增强）
- CameraX拍照 + ML Kit离线OCR识别站牌
- 地铁出入口独立管理，图片备注
- 公交站点绑定地铁出口，接驳标记

三期（体验完善）
- ZIP本地备份导入导出
- 收藏、置顶、线路分组
- 站点拖拽排序，批量编辑
- UI动画细节优化
