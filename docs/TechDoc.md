# 《途记交通备忘录》安卓技术方案文档
英文名：TransNote
包名：com.transnote.traffic
> 核心约束：**纯本地离线应用，不开发后端服务，无服务端接口，用户数据全部保存在手机本地**

## 1. 基础信息
- 平台：Android手机
- 最低SDK：Android10（API29）
- 目标SDK：Android14（API34）
- 网络：可选联网（仅地图瓦片加载需要网络；业务逻辑全部离线）
- 后端：无后台服务、无服务器、无数据库服务端

## 2. 开发语言 & 技术栈
### 编程语言
1. Kotlin：100%业务代码（主语言）
2. XML：仅资源文件（颜色、字符串，业务UI全部使用Compose）

### 框架 & 第三方库
|类别|组件|用途|
| ---- | ---- | ---- |
|UI框架|Jetpack Compose + Material3|页面、组件、主题管理，支持深浅色切换，监听系统暗黑模式|
|架构组件|ViewModel + StateFlow|MVVM架构，屏幕旋转/主题切换时保存页面状态|
|本地数据库|Room Jetpack组件|本地结构化数据库，底层SQLite，存储线路、站点、出入口、备注关系|
|异步处理|Kotlin协程 + Flow|数据库IO、图片文件读写，不阻塞UI线程|
|图片加载|Coil-Compose|加载本地站点图片，缩略图、大图预览|
|相机&OCR|CameraX + Google ML Kit离线OCR|拍照/相册选图，本地离线文字识别，图片不上传|
|地图SDK|高德地图轻量SDK（可选替换百度）|站点打点、线路轨迹绘制；瓦片需要网络。完全断网需求可更换Mapbox离线瓦片|
|本地存储配置|DataStore|持久存储用户主题选择（跟随系统/浅色/深色），替代SP|
|文件处理|Kotlin IO + Zip压缩|本地导出备份ZIP包、导入恢复备份|
|基础工具|Kotlin标准库|字符串模糊搜索、拖拽排序、坐标计算等|

> 不引入：Retrofit、OkHttp、推送SDK、埋点、广告SDK

## 3. 架构设计：MVVM（仅本地数据源，无远程仓库）
分层：UI层 → ViewModel层 → 本地仓库层 → 数据层
1. UI层：Compose页面、组件、弹窗，只监听StateFlow状态，触发用户事件，不直接操作数据库；
2. ViewModel层：接收UI事件，调用本地仓库，执行业务逻辑（新增线路、编辑站点、搜索、切换上行下行、主题管理），使用StateFlow向外暴露状态；
3. Repository本地仓库层：封装Room数据库操作 + 文件IO（图片读写、备份导入导出），**无网络请求**；
4. Data数据层：Room实体类、DAO、数据库实例；图片文件读写工具；
5. Utils工具层：OCR工具、本地搜索工具、坐标工具、拖拽工具、主题管理器。

## 4. 数据库设计（Room）
实体表：
1. City：城市ID、城市名称
2. BusLine：公交线路，所属城市，线路名称，首末班，票价，上行站点列表、下行站点列表
3. BusStation：公交站点，名称，所属线路ID，经纬度，文字备注，图片路径数组，是否接驳地铁，关联地铁出入口ID
4. MetroLine：地铁线路信息
5. MetroStation：地铁站点
6. MetroEntrance：地铁出入口，归属地铁站点ID，出口名称，对应道路，地标备注，文字备注，图片路径，经纬度

关系说明：
- 一条公交线路包含上行、下行两套独立站点集合；
- 一个地铁站点可以关联多个地铁出入口；
- 公交站点可绑定0或多个地铁出入口，实现换乘标记。

## 5. 核心模块技术实现
### 5.1 主题管理模块
- 用户配置存储在DataStore，三个选项：跟随系统 / 浅色 / 深色；
- Compose Material3 内置暗黑模式监听，读取系统isSystemInDarkTheme；
- 内置两套ColorScheme（浅色、深色），所有UI组件引用主题颜色，禁止硬编码色值；
- 切换主题，Compose自动重组页面，实时生效，无需重启APP。

### 5.2 线路录入（手动+拍照OCR）
1. 手动录入：表单录入，支持拖拽排序站点；上行、下行站点独立保存；
2. 拍照录入：CameraX调用相机，支持相册选图；ML Kit离线OCR本地识别文字，自动填充表单，用户手动校对修改；OCR模型本地下载，识别不上传图片。

### 5.3 站点、地铁出入口备注
- 公交站点、地铁出入口为独立数据库实体；
- 图片保存到APP私有存储目录，数据库仅保存图片文件路径；
- 支持存储经纬度，地图上打点；公交站点可绑定地铁出入口ID，页面渲染换乘标签。

### 5.4 线路预览与上行下行切换
- 保存两套站点数据，切换按钮修改状态；StateFlow通知UI刷新站点列表与地图轨迹；
- 地图SDK绘制站点标记，换乘站点高亮。

### 5.5 本地离线检索
1. 正向检索：模糊匹配BusLine、MetroLine的线路名称/编号；
2. 反向地点检索：本地数据库遍历站点名称、站点备注、地铁出口道路/地标字段，返回所有匹配的站点和所属线路，按匹配度排序；
3. 全部使用Kotlin本地字符串匹配，不调用任何外部搜索接口。

### 5.6 本地备份导入导出
- 导出：读取Room数据库文件、APP私有目录图片，压缩为ZIP包，保存到用户选择的本地文件夹；
- 导入：读取本地ZIP，解压覆盖数据库和图片目录，全部为本地文件IO操作。

## 6. 项目目录结构
```
com.transnote.traffic
├── ui                     // Compose UI页面与组件
│   ├── theme              // ColorScheme主题、颜色、字体定义
│   ├── screens            // 首页、线路编辑、站点详情、搜索、设置页
│   └── components         // 卡片、输入框、标签、地图组件等通用组件
├── viewmodel              // 全部ViewModel
├── repository             // 本地仓库，封装Room与文件IO
├── data
│   ├── database           // Room Entity、DAO、Database
│   └── file               // 图片读写、ZIP备份工具
├── utils                  // OCR、搜索、坐标、拖拽、通用工具类
└── MainActivity.kt        // APP入口，挂载Compose
```

## 7. 开发注意事项（纯本地化重点）
1. 没有账号系统、没有云同步，基础版本只提供本地导出备份；APP卸载，私有目录数据全部清除；
2. ML Kit离线OCR首次安装自动下载离线语言包，下载完成后完全离线识别；
3. 地图瓦片需要网络；如果要求完全断网使用，替换为离线瓦片地图；
4. 不添加任何埋点、统计、广告、推送SDK，保证纯净工具；
5. 申请必要权限：相机、读取相册、文件访问权限、定位（地图打点用）。
